# Home Energy Toolkit

Чотири незалежні інтеграції для Home Assistant, які перетворюють зв'язку
**сонячні панелі + акумулятор + нестабільна мережа** у щоденні рішення:
скільки сонця буде, чи вистачить заряду, коли зникало світло і скільки це коштує.

Кожна інтеграція встановлюється та налаштовується окремо — можна взяти лише те,
що потрібно.

| Компонент | Що дає | Залежності |
|---|---|---|
| [`pv_planner`](custom_components/pv_planner/README.md) | Прогноз PV (Forecast.Solar), поточний надлишок сонця, розрахунок потрібного резерву АКБ, порада «гріти / тримати / резерв низький» | інтернет (Forecast.Solar, без API-ключа) |
| [`outage_log`](custom_components/outage_log/README.md) | Журнал відключень мережі: старт, кінець, тривалість, SoC до/після, статистика за день/місяць, календар | `binary_sensor` стану мережі |
| [`energy_cost`](custom_components/energy_cost/README.md) | Гроші: вартість імпорту, дохід з експорту, економія від власного PV, одно- та двозонний тариф | лічильники енергії (`kWh`, `total_increasing`) |
| [`device_watchdog`](custom_components/device_watchdog/README.md) | Сповіщення, коли пристрій або сенсор «відвалився» надовго, і коли повернувся | список сутностей для нагляду |

## Встановлення

1. Скопіюйте потрібні папки з `custom_components/` у `/config/custom_components/`
   на вашому Home Assistant:

   ```
   /config/custom_components/pv_planner/
   /config/custom_components/outage_log/
   /config/custom_components/energy_cost/
   /config/custom_components/device_watchdog/
   ```

2. Перезапустіть Home Assistant.
3. **Налаштування → Пристрої та служби → Додати інтеграцію** і виберіть потрібну.
4. Заповніть поля (усі підказки перекладені українською).

Вимоги: Home Assistant 2026.11+, Python 3.13. Зовнішніх Python-залежностей немає.

## Мова

Усі інтеграції мають `strings.json` + `translations/en.json` + `translations/uk.json`.
Щоб додати мову — скопіюйте `translations/en.json` у `translations/<код>.json`
і перекладіть значення. Перезапуск HA підхопить файл автоматично.

## Принципи

- **Нічого не перемикають самостійно.** `pv_planner`, `outage_log`, `energy_cost`
  лише публікують сенсори. Рішення «увімкнути обігрівач» ухвалює автоматизація —
  її видно, її можна вимкнути, вона не сюрпризить.
- **Дані переживають перезапуск.** Стан зберігається через `Store`.
- **Жодних хмарних акаунтів**, крім безкоштовного прогнозу Forecast.Solar.
- **Локальна робота**: інвертор і пристрої читаються в мережі дому.

## Roadmap

- `inverter_settings` — перегляд і зміна налаштувань інвертора (режим роботи,
  вікна заряду/розряду, ліміт експорту) через Modbus TCP.
  Наразі заблоковано: порт 502 на донглі відкритий, але Modbus не відповідає —
  потрібно увімкнути його в налаштуваннях Pocket WiFi або оновити прошивку.
